# Proje Tanımı ve Kullanım Amacı
Pandemi dönemlerinden sonra Dünya'nın hijyen ihtiyacına karşı sunulan çözümlerden biri olarak tasarladığım projedir. Ultraviyole ışının mikrop öldürücü etkisini kart üzerindeki UV LED ler ile kullandım. PCB'sini proteus, yazılımını ise MplabXIDE ve Microchip PIC 8 serisi ile gerçekleştirdim.
